# WAVUtils Architecture## OverviewWAVUtils is a C# .NET 10.0 desktop application for merging and splitting multi-channel WAV files. It consists of three projects: a CLI application (`WAVUtils.App`), a core library (`WAVUtils.Core`), and a system tray application (`WAVUtils.Tray`). Merge Flow (7 steps)```Program.Main → RunMerge → MergeCommand.Run → BuildMergedFile → WriteChunk```1. `Program.Main` parses CLI args and dispatches to `RunMerge`2. `MergeCommand.Run` reads WAV metadata via `WavMetadataChunk.ReadWavChunks`3. `ExtractTypedMetadata` parses bEXT, iXML, INFO, cue, smpl, adtl chunks4. `BuildMergedFile` iterates input files and writes merged output5. `WriteChunk` writes each WAV chunk to the output stream### 2. Split Flow (7 steps)```Program.Main → RunSplit → SplitCommand.Run → ReadPmalChunks → AppendChunksToOutput```1. `Program.Main` dispatches to `RunSplit`2. `SplitCommand.Run` reads per-channel metadata3. `ReadPmalChunks` identifies channel layout4. `AppendChunksToOutput` writes each channel to a separate output file5. `WriteChunkToStream` serializes chunks to binary### 3. Typed Metadata Extraction (7 steps)```Program.Main → WavChunkParsers.ExtractTypedMetadata → Parse → BextChunkData.ReadAsciiNullTerminated```1. `ReadWavChunks` reads raw WAV chunks from stream2. `ExtractTypedMetadata` dispatches to typed parsers3. Each chunk type (bEXT, iXML, INFO, cue, smpl, adtl) has its own parser class4. `ReadAsciiNullTerminated` handles string fields in chunk data## Key Components### MergeCommand (`MergeCommand.cs:11-276`)Handles the merge operation.
