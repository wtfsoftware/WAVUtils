# Master plan — WAVUtils

Use this ledger to prioritize changes and distinguish verified defects from review candidates. The audit was documentation-only; the accepted [remediation plan](2026-11-25-audit-remediation.md) also changes application code and adds permanent tests. Original recordings remain untouched. Estimates include focused regression checks, not a release or data migration.

## Verification

The original audit built with seven warnings. Its temporary Core probes passed
the PCM16 baseline and reproduced 15 failures. The remediation has a permanent
Windows gate: the strict local Release build reports no warnings and all 187
tests pass, including the width-cap cases in #75. See
[remediation verification](2026-11-25-audit-remediation.md#verification)
for separate portable-binary checks and remaining integration risks.

Verification uses generated WAV files in a sandbox. It does not run Setup,
change the registry or camera settings, modify production recordings, or
publish a release.

## Sources

[1] [EBU Tech 3285: Broadcast Wave Format, version 2](https://tech.ebu.ch/docs/tech/tech3285.pdf), pp. 9–11. The specification declares an 8-byte `OriginationTime` and states: “8 ASCII characters containing the time of creation of the audio sequence.” The field offsets in #34 follow from the declared field lengths and agree with the independent `ffprobe` check.

[2] [EBU Tech 3306: RF64, January 2006](https://samples.mplayerhq.hu/A-codecs/sf/rf64.pdf), section 3.4 and annex A.2. The 32-bit fields use their own values unless set to `0xFFFFFFFF`, and `sampleCount` in `ds64` replaces the count in `fact`.

[3] [Inno Setup: Non Administrative Install Mode](https://jrsoftware.org/ishelp/topic_admininstallmode.htm). An administrative installer should not write settings for an individual user.

[4] [Microsoft: Resource Interchange File Format](https://learn.microsoft.com/en-us/windows/win32/xaudio2/resource-interchange-file-format--riff-). RIFF chunks have a FourCC, a data size, and word alignment.

[5] [WAVRef: Associated Data List](https://wavref.til.cafe/chunk/adtl). Associated labels and notes are subchunks of `LIST/adtl`.

[6] [Microsoft: about_Character_Encoding (Windows PowerShell 5.1)](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_character_encoding?view=powershell-5.1). Windows PowerShell reads a BOM-less script with the legacy code page.

[7] [GitHub REST API: Release assets](https://docs.github.com/en/rest/releases/assets?apiVersion=2026-03-10). Asset metadata exposes `size`, `digest`, and `browser_download_url`.

[8] [Microsoft: `New-Item` in Windows PowerShell 5.1](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/new-item?view=powershell-5.1). Creating an existing registry key with `-Force` overwrites its values. Use literal paths for existing keys and executable checks.

[9] [Inno Setup: Appending to Existing Uninstall Logs](https://jrsoftware.org/ishelp/topic_appendnotes.htm). An in-place upgrade can append to the old log, so uninstall can undo changes made by earlier installers.

[10] Inno Setup: [`UsePreviousAppDir`](https://jrsoftware.org/ishelp/topic_setup_usepreviousappdir.htm) defaults to `yes`; [`/DIR`](https://jrsoftware.org/ishelp/topic_setupcmdline.htm) overrides the destination shown in the wizard.

[11] [Microsoft: `Version.CompareTo`](https://learn.microsoft.com/en-us/dotnet/api/system.version.compareto?view=net-10.0). .NET ranks an omitted component below a known one, including zero.

[12] [Microsoft: Windows PowerShell execution policies](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_execution_policies?view=powershell-5.1). `Restricted` is the client default, and Group Policy overrides session settings.

## Deploy note

To refresh Explorer commands for a Windows account, run `Install.ps1` from the
intended WAVUtils folder without elevation. Reinstalling Setup alone no longer
changes the account's menu or autostart.
