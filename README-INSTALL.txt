WAVUtils v1.0.0
Multi-channel WAV merge and split utility

INSTALLATION
  The installer will copy WAVUtils to your Program Files directory
  and add context menu entries for merging and splitting WAV files.

CONTEXT MENU
  Right-click any WAV files in Explorer to merge them together.
  Right-click a multi-channel WAV file to split it into tracks.
