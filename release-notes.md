- **Multi-language installer** - 6 languages (EN, RU, DE, FR, ES, JA, ZH) with auto-detection of OS language
- **Copyright updated to 2026**
- **Bug fixes and improvements**

## Download

- **Installer**: WAVUtils-Setup-1.1.0.exe (36.5 MB, Windows x64)
- **Portable**: WAVUtils-1.1.0-Portable.zip (48.9 MB, no installation required)

## CLI Usage

```
WAVUtils.exe merge file1.wav file2.wav [...fileN.wav] [output.wav]
WAVUtils.exe split merged.wav
WAVUtils.exe check-update
```
